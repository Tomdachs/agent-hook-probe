# Code of Conduct

We want project discussions to stay useful, respectful, and focused on improving the software.

Be constructive, assume technical disagreement is normal, and avoid harassment, personal attacks, discriminatory language, or publishing another person's private information. Maintainers may edit, hide, or remove contributions that undermine a safe and productive project space and may restrict participation for repeated or severe violations.

For conduct concerns that should not be public, contact the repository owner privately through the GitHub profile.
